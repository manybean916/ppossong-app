# 뽀송퇴근 🧺

> 직장인을 위한 스마트 세탁 가이드 서비스

## 기능

- 🌡️ **습도 기반 배경 전환** — 70% 이상이면 눅눅한 회색, 미만이면 뽀송한 파란색
- ✅ **세탁 가능 여부 메시지** — "오늘 퇴근 후 빨래해도 돼요!" / "절대 금지, 쉰내 납니다"
- 🌀 **건조기 유무 체크** — 상황별 맞춤 세탁 가이드 제공
- ⚡ **에너지 팁** — 전기요금 피크·심야 시간대 안내
- 🔌 **세탁기 기기 정보** — 소비전력 500Wh, 상태 표시

## 파일 구조

```
ppossong_app/
├── index.html   # UI 마크업
├── style.css    # 테마 스타일 (습도 기반 전환)
├── app.js       # 기상청 API 연동 + 로직
└── README.md
```

## 기상청 API 연동

`app.js` 상단의 두 값을 입력하면 실데이터로 전환됩니다:

```js
const KMA_API_KEY = '여기에_기상청_API_키_입력';
const STATION_ID  = '108'; // 108 = 서울
```

API 키 미입력 시 Mock 데이터(65% 습도)로 동작합니다.

## 실행 방법

```bash
# 브라우저에서 바로 열기
open index.html

# 또는 로컬 서버
npx serve .
```
